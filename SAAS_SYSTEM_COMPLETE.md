## 🚀 HOW TO USE

### 1. **Start the System**
```bash
node server.js
# Open: http://localhost:3000
# Click "ENTER HQ" for SaaS management
```

### 2. **Import Leads**
- Go to Leads tab
- Use CSV Import section
- Paste CSV data with headers: name,email,phone,company,source,service
- Click "Import Leads"

### 3. **Manage Pipeline**
- Go to Pipeline tab
- Add deals manually or convert leads
- Move deals between stages
- Track pipeline value

### 4. **Set Up Subscriptions**
- Go to Services tab
- Add subscription details
- Set billing cycles (Monthly/Quarterly/Yearly)
- Click "Check Due Billings" for automated billing

### 5. **Monitor Dashboard**
- Dashboard shows all key metrics
- Real-time updates after each action
- Advanced analytics and trends
